# Фотографии

Все фото задаются в `src/config.js` (в Тильде — в блоке 1). Сейчас там временные
снимки с Unsplash. Если фото не загрузится, на его месте будет аккуратная
тёплая заглушка с подписью слота — вёрстка не развалится.

Рекомендуемые имена файлов, если кладёте фото в эту папку
(в конфиге тогда пишите `assets/photos/hero.webp` и т. д.):

| Ключ в конфиге            | Файл                          | Пропорции / размер      |
|---------------------------|-------------------------------|-------------------------|
| `photos.hero`             | `hero.webp`                   | вертикальное, 1200×1800 |
| `photos.splash`           | `splash.webp` (необязательно) | вертикальное, 1200×1800 |
| `photos.guests`           | `guests.webp`                 | 4:5, 800×1000           |
| `photos.venue`            | `venue.webp`                  | 3:4, 900×1200           |
| `photos.final`            | `final.webp`                  | вертикальное, 1200×1800 |
| `story.items[0..4].photo` | `story-01.webp … story-05.webp` | почти квадрат, 800×900 |
| `gallery.photos[…]`       | `gallery-01.webp … gallery-09.webp` | 4:5 или 3:4, 900×1200 |
| `dresscode.refs[0..2].src`| `dress-01.webp … dress-03.webp` | 3:4, 600×880          |

Советы: WebP с качеством 70–80, длинная сторона не больше 1800 px —
так сайт быстро открывается по мобильному интернету. Тёплая плёночная
обработка и зерно накладываются автоматически.
