# Слоты под декоративную графику

Сейчас вместо файлов рисуется встроенная линейная ботаника (тонкие SVG-веточки,
которые «прорисовываются» при прокрутке). Чтобы заменить её своей графикой,
положите в эту папку PNG с прозрачным фоном **ровно с таким именем** — сайт
подхватит файл сам (для Тильды впишите прямую ссылку на картинку в `decor` в конфиге).

| Файл                  | Где на сайте                          | Рекомендуемый размер |
|-----------------------|---------------------------------------|----------------------|
| `decor-branch-01.png` | веточка над цитатой                   | 400 × 140            |
| `decor-branch-02.png` | веточка под цитатой и в «Спасибо!»    | 300 × 110            |
| `decor-sprig-03.png`  | вертикальная веточка у «Дорогие гости»| 180 × 330            |
| `decor-floral-04.png` | ботаника у календаря                  | 240 × 250            |
| `decor-branch-05.png` | ветка над контактами в финале         | 340 × 120            |

Чтобы спрятать элемент совсем — поставьте в конфиге `false` вместо `true`.
