# Артур & Анна · свадебное приглашение · 23.07.2027

Мобильный лендинг-приглашение: заставка со стиранием, hero с типографикой имён,
календарь, таймер, тайминг, локация, трансфер, дресс-код, история, галерея,
анкета гостя с отправкой в Google Таблицу.

Чистые HTML + CSS + JS без фреймворков и внешних библиотек.

```
index.html            — страница для своего хостинга / GitHub Pages
src/config.js         — ВСЕ тексты, даты, ссылки, фото (правьте только его)
src/styles.css        — оформление (цвета — CSS-переменные в :root)
src/app.js            — сборка секций из конфига и всё поведение
tilda/                — готовые блоки для Тильды (собираются из src/)
build-tilda.mjs       — пересборка блоков для Тильды: node build-tilda.mjs
google-apps-script/   — скрипт приёма анкет в Google Таблицу
assets/fonts/         — Florisel Script, Lora (исходные TTF + WOFF2)
assets/decor/         — слоты под декоративную графику (см. README там)
assets/photos/        — место под ваши фото (см. README там)
assets/favicon/, assets/og/ — фавикон и картинка для превью ссылки
references/           — референсы
```

## Тильда

1. Создайте пустую страницу. В настройках страницы → «Дополнительно» можно
   задать цвет фона `#DCD9CB` (будет виден по бокам на компьютере).
2. Добавьте блоки **T123 «HTML-код»** (раздел «Другое») по порядку и вставьте
   содержимое файлов из папки `tilda/`:

   | Блок | Файл                                | Что внутри                         |
   |------|-------------------------------------|------------------------------------|
   | 1    | `01-config.html`                    | конфиг: тексты, даты, ссылки, фото |
   | 2    | `02-fonts.html`                     | шрифты (по ссылке, ~1 КБ)          |
   | 3    | `03-styles.html`                    | стили                              |
   | 4    | `04-script.html`                    | скрипт                             |
   | 5    | `05-splash-hero-quote.html`         | заставка, hero, цитата             |
   | 6    | `06-guests-date-countdown.html`     | обращение, календарь, таймер       |
   | 7    | `07-timing-location-transfer.html`  | тайминг, локация, трансфер         |
   | 8    | `08-dresscode-story.html`           | дресс-код, история                 |
   | 9    | `09-gallery-rsvp-final.html`        | галерея, анкета, финал             |

   Блоки 1–4 невидимые и должны стоять **выше** остальных. Блоки 5–9 можно
   добавлять по одному. Florisel Script грузится из этого репозитория через
   jsDelivr (ссылка закреплена на коммите), Lora — из Google Fonts.
   Стили и скрипт в блоках минифицированы; пересборка: `npm install && npm run build:tilda`.
3. Результат виден в **«Предпросмотре»** или после публикации — в самом
   редакторе Тильда HTML-блоки не исполняет.
4. Настройки страницы → «Соцсети»: заголовок «Артур и Анна · 23.07.2027»,
   описание и картинка `assets/og/og-image.jpg` (лучше заменить на фото пары
   1200×630). Фавикон: настройки сайта → «Ещё» → иконка, файл
   `assets/favicon/icon-512.png`.
5. Фото для Тильды: загрузите файлы в любой блок/«Файлы» Тильды, скопируйте
   ссылку `https://static.tildacdn.com/…` и вставьте в блок 1.

## Анкета → Google Sheets

1. Создайте Google Таблицу → «Расширения» → «Apps Script».
2. Вставьте код из `google-apps-script/Code.gs`, сохраните.
3. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение».
   Выполнять от имени: **вы**; доступ: **все (Anyone)**. Разрешите доступ.
4. Скопируйте URL вида `https://script.google.com/macros/s/…/exec` и вставьте
   в конфиг: `rsvp.formUrl: '…'`.
5. Отправьте тестовую анкету — в таблице появится лист «Ответы».

Пока `formUrl` пустой, форма работает в демо-режиме: показывает благодарность,
но ничего не отправляет. Встроено: проверка обязательных полей, блокировка
кнопки на время отправки, игнор повторной отправки той же анкеты, ловушка
для ботов, защита таблицы от формул.
После изменения кода Apps Script делайте «Управление развёртываниями →
Изменить → Новая версия», иначе URL продолжит работать со старым кодом.

## Свой хостинг / GitHub Pages

Залейте папку целиком; откройте `index.html`. Для GitHub Pages: Settings →
Pages → Branch `main` / root. В `index.html` поправьте `og:url` и при желании
`og:image` на абсолютную ссылку.

## Что заменить перед публикацией

- [ ] Фото: `photos`, `story.items[].photo`, `gallery.photos`, `dresscode.refs` (конфиг).
- [ ] Площадка: название, адрес, ссылки Яндекс/Google Карт.
- [ ] Трансфер: место сбора, время, ссылка на карту.
- [ ] Наша история: даты и тексты.
- [ ] Контакт организатора: имя и телефон.
- [ ] `rsvp.formUrl` — URL веб-приложения Google Apps Script.
- [ ] Время начала и часовой пояс: `eventStart` (сейчас 15:00 по Москве).
- [ ] OG-картинка и `og:url` (для своего хостинга) / настройки соцсетей в Тильде.
- [ ] По желанию — своя графика в слоты `decor-*.png`.

## Доступность и производительность

- Mobile-first, проверено на 360 / 375 / 390 / 414 / 430 px и на десктопе
  (колонка 520 px с размытым фото по бокам); горизонтального скролла нет.
- `100dvh`, `safe-area-inset`, поля формы 17 px (iOS не зумит), зоны нажатия ≥ 44 px.
- `prefers-reduced-motion`: анимации заменяются мягким появлением.
- Фото: `loading="lazy"`, `srcset` (Unsplash отдаёт WebP/AVIF), шрифты WOFF2 с `font-display: swap`.
- Без JavaScript-библиотек: скрипт ~50 КБ, стили ~47 КБ (до сжатия).
